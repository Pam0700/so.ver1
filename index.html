Tra cứu Ship / Code

Tải dữ liệu

Tải file giao hàng (dg1) và file sản phẩm (50, 54...). Nhận cả .xlsx lẫn .csv gốc lỗi font.

Chọn & xử lý

Chọn Ship hoặc Code cần lấy, đặt cách sắp xếp rồi bấm Xử lý.

Chọn dữ liệu

Hoặc dán nhiều code (cách nhau bằng dấu cách, phẩy hoặc xuống dòng):

Sắp xếp
Mỗi khách hàng nằm trọn trong 1 vùng; các vùng cách nhau 1 dòng trống.
Sản phẩm khớp từ khoá nào đứng trước theo thứ tự này; không khớp thì xếp cuối theo A-Z.

Kết quả

Chưa có kết quả. Vào "Chọn & xử lý" và bấm Xử lý.

Điền form báo cáo

Cần bấm Xử lý trước. Dữ liệu được điền vào form theo từng vùng, tự nhân bản vùng khi nhiều dữ liệu.

Chuyển CSV gốc

Sửa lỗi font và lọc dữ liệu từ file CSV tải về, xuất ra .xlsx. (Không bắt buộc: các ô tải ở bước 1 cũng nhận thẳng file CSV.)

Quy ước rút gọn

Rút gọn tên khách hàng / điểm giao và tên sản phẩm. Sau khi nạp quy ước, bấm Xử lý lại để áp dụng.
